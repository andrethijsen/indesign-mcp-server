# InDesign MCP Server

Ceci est un fork du projet 'indesign-mcp-server' de **lucdesign** (https://github.com/lucdesign/indesign-mcp-server).
Il corrige des incompatibilités sous Tahoe / indesign 2026.


## 📋 Prerequis

- **Adobe InDesign 2026** 
- **macOS** (required for AppleScript integration)git add .
- **Node.js 18+**
- **MCP-compatible client** (Comme Antigravity ou Claude Desktop)

## 🛠️ Installation

### 1. Clone the Repository
```bash
git clone https://github.com/andrethijsen/indesign-mcp-server.git
cd indesign-mcp-server
```

### 2. Install Dependencies
```bash
npm install
```
